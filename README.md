# Ambiente de desenvolvimento "genérico"

O Objetivo desse projeto, é criar um ambiente de desenvolvimento "genérico" incluindo diversas bibliotecas que são usadas em praticamente qualquer projeto.

## Como usar

A unica coisa que você precisa é rodar o script bash "install.sh" e um sistema debian será instalado no seu sistema.

## Requisitos

A unica coisa necessária para rodar esse script é ter o docker e o distrobox instalados.
